# The paper

*Reading the Robot Mind on GPT-2: what a training-free, human-readable
readout recovers, and where it stops* — Paul Alton Nussbaum, PhD.

Current version: **v9** (`paper_v9.tex` / `paper_v9.pdf`), the first
version to include the blind reading test results. The paper accompanies
the experiment records in this repository: the confirmatory records in
`post-book-experiments/`, the follow-ups and the referee exchange in
`ai-rtrm-experiments/`. Not yet submitted to arXiv.
