# Post-book experiments

Follow-up studies done after *Applications of Reading the Robot Mind(R)*
was published, using the book's methods on new questions. Each study is a
self-contained folder with a plain-words restatement for the domain expert
and the lab record (run scripts, results, summaries, audits) for the
analyst.

## Studies

- [pronoun-resolution/](./pronoun-resolution/) — Can the RTRM
  cosine-similarity method surface what a pronoun refers to in GPT-2?
  (exp-052 through exp-055, September 2026.)

## Book & reference
